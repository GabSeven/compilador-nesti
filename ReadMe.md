# Implementação de um Compilador 
Esse é um trabalho da disciplina de Compiladores - 2026.
A tarefa é montar um compilador para a linguagem Nesti,
desenvolvida exclusivamente para esse trabalho.

como rodar:
```
python compilador.py arquivo_de_entrada.nesti
python compilador.py arquivo_de_entrada.nesti > saida.mepa
```
